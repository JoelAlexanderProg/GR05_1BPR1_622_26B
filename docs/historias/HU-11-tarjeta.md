# HU-11 · Retirar un reporte propio

| Campo | Valor |
|---|---|
| Prioridad | Alta |
| Estimación | 3 puntos |
| Tema | TH-01 EncuentraEPN |
| Épica | E1 Registrar objetos perdidos o encontrados (CU-01) |
| Feature | F1 Reporte de objetos |

**Historia:** Como reportante quiero retirar un reporte que publiqué para que deje de aparecer en el mapa cuando ya no hace falta.

**Deseo del usuario:** «Ya recuperé lo que perdí, pero mi reporte sigue en el mapa y la gente lo sigue reclamando.»
